**常规问题：**
- **Q: 为什么程序自启动不生效？**
  A: 请检查程序路径中是否包含中文或空格。
- **Q: 为什么首页只显示 4 个配置项？**
  A: 这是程序的设计。您可以在配置页面调整各项的显示顺序。
- **Q: 遇到 "403 API rate limit exceeded" 错误怎么办？**
  A: 1. 前往 GitHub 开发者设置，获取一个 Personal Access Token (PAT)。
  2. 在客户端的 **软件设置 -> 通用** 中，将 Token 填入 **向 REST API 进行身份验证** 一栏。
- **Q: 订阅没有流量信息，或更新时提示 "Not a valid subscription data"？**
  A: - **通用方法**：在 **订阅 -> 编辑** 中，为该订阅添加请求头 `User-Agent: Clash.Meta`。
  - **GUI.for.SingBox 额外步骤**：
    1. 确保已安装并启用 **节点转换** 插件。
    2. 或更换为原生支持 sing-box 的订阅链接。
  - 最后，请确保您的网络能正常访问该订阅链接。
- **Q: 如何更换托盘图标？**
  A: 1. 前往 **设置 -> 打开应用程序文件夹**。
  2. 替换 `data/.cache/icons` 目录下的图标文件即可。
- **Q: Linux 系统下界面文字位置偏高怎么办？**
  A: 尝试安装 `Noto-Sans-CJK` 和 `Microsoft-YaHei` 字体后重启系统。
- **Q: 在有多网卡的设备上，启动客户端后网络异常？**
  A: 1. 前往 **配置设置 -> 路由设置 -> 通用**。
  2. 禁用 `自动检测出站接口`。
  3. 在下方的接口名称列表中，手动选择您想使用的出站网卡。

**内核与配置问题：**
- **Q: 如何导入单个节点链接？**
  A: 1. 在插件中心安装并运行 **节点转换插件**。
  2. 粘贴节点链接，选择配置格式，然后复制转换后的节点配置。
  3. 将复制的内容添加至 **手动管理订阅**。
  4. 在 **配置设置** 的 **出站分组** 或 **代理组** 中引用该节点。
- **Q: 如何使用自己的（远程/本地）完整配置文件？**
  ||A: 客户端不支持直接导入，但可变通实现：
  - **GUI.for.Clash**: 添加订阅时，勾选 **使用订阅内的策略组和分流规则**。
  - **GUI.for.SingBox**: 在 **配置设置 -> 混入和脚本 -> 脚本操作** 中，使用脚本读取并返回您的本地或远程 sing-box 配置文件内容。||
- **Q: GUI.for.SingBox 启动内核报错 "timeout"？**
  A: Sing-box 缓存文件被占用。请在任务管理器或系统监视器中手动结束所有 `sing-box` 进程，然后重启内核。
- **Q: GUI.for.SingBox 启动内核报错 "detour to an empty direct outbound makes no sense"？**
  A: 新版 sing-box 禁止 DNS 出站设为 `direct`。
  1. 前往 **配置设置 -> DNS 设置 -> 服务器**。
  2. 找到“出站”标签为 `直连` 的服务器，点击 **编辑**。
  3. 点击出站标签旁的 **x** 按钮将其清除（留空即默认为直连）。
- **Q: GUI.for.SingBox 启动内核报错 "missing tags"？**
  A: 某个出站分组为空。
  1. 前往 **配置设置 -> 出站设置**。
  2. 找到左侧有红色感叹号的出站分组，点击 **编辑**。
  3. 确保该分组内至少包含一个订阅或有效节点。

**TUN 模式问题：**
- **Q: 启用 TUN 模式提示没有权限？**
  A: - **Windows**: 在 **设置 -> 通用** 中，勾选 **以管理员身份运行** 并重启客户端。
  - **macOS/Linux**: 在 **设置 -> 内核** 页面，点击授权按钮为内核程序授权。
- **Q: 启用 TUN 模式后无法上网？**
  A: - 尝试在软件设置中更换 **TUN 堆栈模式**。
  - 检查系统防火墙，确保客户端及内核程序未被阻止。
  - **GUI.for.SingBox (macOS)**: 将系统 DNS 更改为公共 DNS（如 `8.8.8.8`）。
  - **网络不支持 IPv6**:
    1. 在 **入站设置 -> tun-in** 中删除 IPv6 地址前缀，并启用严格路由。
    2. 在 **DNS 设置** 中将解析策略设为 **仅使用 IPv4**。
- **Q: TUN 模式下出现 SSL 错误？**
  A: 尝试将您电脑的 DNS 设置为公共 DNS 地址，例如 `8.8.8.8`。
- **Q: GUI.for.SingBox 启用 TUN 报错 "The system cannot find the file specified"？**
  A: Sing-box 创建 TUN 网卡失败。
  1. 检查 `tun-in` 的 **TUN 网卡名称** 设置项是否为空，可尝试填入任意名称（如 `tun0`）后重启内核。
  2. 检查并关闭其他可能冲突的虚拟网卡或网络服务。

**版本与插件：**
- **Q: 滚动发行插件无法更新版本？**
  A: 请先更新 **滚动发行** 插件本身。若问题依旧，可尝试删除程序目录下的 `data/rolling-release` 文件夹。
- **Q: 滚动发行插件提示无法跨大版本升级？**
  A: 滚动发行插件只在最新的大版本上工作。当发布新的大版本后，请前往 **设置 -> 关于更新** 进行手动升级。
